# Automation and Orchestration Scripts

This directory will contain shell and Python utility scripts for environment setup, data ingestion, pipeline orchestration, and cluster management.

## Planned Scripts
- Cluster startup / shutdown hooks (`start_cluster.sh`, `stop_cluster.sh`).
- HDFS data transfer scripts (`upload_to_hdfs.sh`).
- Hive schema execution runners (`init_hive.sh`).
- Batch training and evaluation triggers (`run_pipeline.py`).

# Disease Profiles Configuration

This directory is reserved for domain-specific clinical and disease profile configurations (e.g., Diabetes, Heart Failure, COPD, CKD) for the FHIR and Disease Profiles layer.

## Purpose
- Define clinical rule overlays and risk threshold definitions per condition.
- Map ICD-9 / ICD-10 diagnostic codes to standardized clinical categories.
- Provide custom feature weighting configurations for specialized disease cohorts.

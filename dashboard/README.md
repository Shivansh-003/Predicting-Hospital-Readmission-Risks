# Streamlit Clinical Dashboard

This directory will contain the interactive user interface for healthcare practitioners and clinical administrators.

## Planned Capabilities
- **Streamlit** multi-page application.
- Real-time readmission risk calculator and score visualizer.
- Feature importance and clinical factor explainability breakdown.
- Interactive **Patient Risk Simulator** (counterfactual "what-if" scenario testing).
- Comparative model evaluation leaderboard and performance metrics.
